# Embeddable charts

This directory serves standalone, iframe-able versions of AMEND chart includes so
they can be embedded in external tools (e.g. ArcGIS StoryMaps, news articles,
presentations). Each page is a self-contained HTML document that renders a single
interactive chart; embed one with:

```html
<iframe src="{{ site.url }}/embeds/MAEEADP_through_2025_annual_count.html"
        width="680" height="460" style="border:none"></iframe>
```

Charts render at 640×400 pixels (responsive below that width). The underlying
chart HTML lives in `docs/_includes/charts/` and is regenerated by the analysis
pipeline; these pages update automatically with it.
